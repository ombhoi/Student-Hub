## 📋 Folder Summary

| Folder       | Purpose                                                    |
| ------------ | ---------------------------------------------------------- |
| `/`          | Root – contains `index.html` (homepage) and docs           |
| `admin/`     | Admin panel HTML page                                      |
| `page/`      | All public pages (login, register, dashboard, etc.)        |
| `css/`       | Global stylesheet (`style.css`)                            |
| `js/`        | JavaScript files (currently empty)                         |
| `image/`     | Website logos and images used across pages                  |
| `draw-img/`  | Exported wireframe screenshots (PNG) + wireframe doc       |
| `Drawio/`    | Editable Draw.io source files for wireframes and sitemaps  |
